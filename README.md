# 顔出しなしデジタル制作スタジオ ── 事業運営ドック

スマホ完結・匿名・合法で「月利益30万円」を目指す受注型ビジネスの運営一式です。
実務（制作・文章作成・デザイン・設計）は実務責任者（AI）が担当し、オーナーはスマホで承認と窓口対応のみを行います。

## このビジネスの要点（3行）
- **何を売るか**：文章・記事・資料・デザインなどのデジタル制作（ココナラで受注）
- **誰が作るか**：実務はすべて実務責任者（AI）が納品物を用意。オーナーはコピペと承認のみ
- **なぜ勝てるか**：通常この商売の上限は「人間1人の作業時間」。実務をAIが担うことで件数の壁が外れる

## 合格ライン（KPI）
| 指標 | 目標 |
|---|---|
| 月間利益（手数料・経費差引後） | **300,000円** |
| ココナラ手数料 | 販売額の22%（税込）→ 逆算で月の販売総額 約385,000円が目安 |
| ランニングコスト上限 | 月3,000〜5,000円（または利益確定分から充当） |
