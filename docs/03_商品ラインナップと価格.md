# 03. 商品ラインナップと価格設計

## 基本戦略：2フェーズ価格
ココナラは**実績（販売件数・評価）が表示順位と成約率を左右**します。
そのため最初は意図的に安く出して実績を積み、評価が貯まったら値上げします。

- **フェーズ1（実績ゼロ〜10件）**：相場より安い「実績解除価格」で受注を取りに行く
- **フェーズ2（評価10件・星4.8以上）**：標準価格へ。リピーター・指名で安定化

## 主力商品（текст系＝AIが高品質・高速で全納品できる領域を優先）

## 30万円までの逆算（手数料22%考慮）
利益30万 → 販売総額 約385,000円が必要。

例：フェーズ2の構成で月あたり
- SEO記事 7,000円 × 25件 = 175,000円
- 資料作成 15,000円 × 8件 = 120,000円
- 応募書類 4,500円 × 15件 = 67,500円
- プロフィール等 3,000円 × 10件 = 30,000円
- **合計 392,500円 → 手数料差引 約306,000円** ✅

> 件数は多く見えますが、制作実務はAIが担うため処理可能な水準です。
> オーナーの作業は各案件「転送・コピペ・承認」のみ。

## 自動化レッグ（並行・追加コストほぼ0）
受注で作った成果物を匿名で**テンプレート商品化**し、後日 BOOTH / ココナラの「テンプレート販売」で作り置き販売へ。
例：「そのまま使える企画書テンプレ」「SEO記事構成テンプレ集」など。
受注が安定したら比重を移し、徐々に放置でも売れる在庫を増やす。
