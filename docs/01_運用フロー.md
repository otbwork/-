# 01. 運用フロー ── オーナーのスマホ作業はこれだけ

## 役割分担
| 工程 | 担当 | 内容 |
|---|---|---|
| ① 商品設計・出品文作成 | 実務責任者(AI) | 売る商品・価格・説明文を全部用意 |
| ② 出品操作 | オーナー | AIが用意した文をコピペして出品（スマホ） |
| ③ 問い合わせ受信 | オーナー | 通知が来たら本文をAIに転送 |
| ④ 見積・返信文作成 | 実務責任者(AI) | 返信文を作成 |
| ⑤ 返信送信 | オーナー | コピペして送信 |
| ⑥ 制作 | 実務責任者(AI) | 記事・資料・デザイン等を全納品 |
| ⑦ 納品内容の承認 | オーナー | 中身を確認しOKを出す |
| ⑧ 納品送信 | オーナー | 納品物＋メッセージをコピペ送信 |
| ⑨ 評価促進・リピート誘導 | 実務責任者(AI) | フォロー文を用意 |

**オーナーの実作業 = 「転送」と「コピペ」と「承認」だけ。1案件あたり実質5〜10分。**

## 1日の流れ（慣れたら15〜30分）
1. 朝：ココナラ通知を確認 → 新規問い合わせがあればAIに転送
2. AIが返信文・見積を作成 → コピペして返信
3. 受注 → AIが制作 → 内容を承認 → 納品をコピペ送信
4. 夜：評価・リピート誘導のフォロー文を送信

## AIへの転送フォーマット（これをコピペして使う）
問い合わせが来たら、以下の形でそのまま貼ってください。

```
【新規問い合わせ】
商品名：（どの出品か）
お客様の依頼内容：
（メッセージ本文をそのまま貼り付け）
納期希望：
予算感：
```

→ 実務責任者が「返信文」または「納品物」を返します。

|---|---|---|---|---|
