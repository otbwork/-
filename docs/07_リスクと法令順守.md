# 07. リスクと法令順守（やってはいけないこと）

> 「合法・誠実」はこのビジネスの絶対条件です。短期の利益のためにここを崩すと事業ごと失います。

## 絶対にやらないこと
- **学校の課題・レポート・論文の代行**（多くの教育機関で不正行為。ココナラでも規制対象になりうる）
- **資格試験・採用試験の替え玉、なりすまし**
- **嘘の経歴・虚偽実績の作成**（応募書類は「魅力的に整える」までで、経歴の捏造はしない）
- **薬機法・景表法に反する文章**（医療・健康・美容で効果を断定する表現、誇大広告）
- **他者の著作物の無断転載・コピペ納品**（必ずオリジナルで制作）
- **公序良俗に反する内容、誹謗中傷、差別的表現**
- **ココナラ外での直接取引の誘導**（規約違反。アカウント停止リスク）

## グレーを避ける判断基準
迷ったら「**それが公になっても胸を張れるか**」で判断。少しでも怪しければ受けない（断り文は `docs/05` の8番）。

## 表記・品質のルール
- 納品物は**オリジナルで作成**し、必要に応じてコピペチェックの観点も意識
- 事実主張を含む記事は、断定を避け誤情報を載せない
- 医療・法律・金融など専門領域は「一般情報」の範囲にとどめ、断定や個別助言を避ける

## 税務（利益が出たら）
- 個人の副業所得が一定額を超えると**確定申告が必要**（目安：給与所得者で副業所得20万円超／年）。
- ココナラの売上明細・手数料・経費（ツール代等）は記録を残す。
- 安定して30万/月に近づいたら、開業届・青色申告も検討（節税）。
- ※ 具体的な税務判断は、必要に応じて税理士・税務署に確認を。

## アカウントを守る
- 規約は定期的に変わる。`ココナラ利用規約`は時々確認。
- 評価・信用が最大の資産。低評価を避けるため、無理な納期・苦手分野は受けない。
- 1プラットフォーム依存はリスク → 軌道に乗ったら販路を分散（BOOTH等）。
