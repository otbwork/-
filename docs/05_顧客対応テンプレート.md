# 05. 顧客対応テンプレート（返信のコピペ集）

> 迷ったら、問い合わせ本文を実務責任者(AI)に転送してください。状況に合わせた最適な返信を作成します。
> 以下は「すぐ返したい」時の汎用テンプレートです。

## 1. 初回問い合わせへの返信
```
お問い合わせありがとうございます。
ご相談いただいた件、対応可能です。

より正確にご案内するため、以下を教えていただけますか？
・◯◯（テーマ／目的）
・希望納期
・分量やご予算の目安

いただいた内容をもとに、最適なご提案とお見積りをお出しします。
どうぞよろしくお願いいたします。
```

## 2. 見積提示
```
ありがとうございます。内容を確認しました。
今回のご依頼ですと、以下でご案内できます。

・内容：◯◯
・料金：◯◯円
・納期：ご購入から◯日

ご不明点があればお気軽にどうぞ。
ご納得いただけましたら、ご購入手続きをお願いいたします。
```

## 3. 受注直後（着手連絡）
```
ご購入ありがとうございます。さっそく着手いたします。
◯日までに納品予定です。
進行中にご確認したい点が出ましたら、こちらからご連絡します。
```

## 4. 納品時
```
お待たせいたしました。ご依頼の◯◯をお届けします。
（※納品物を添付）

ご確認いただき、修正のご希望があればお知らせください（2回まで無料です）。
ご満足いただけましたら、正式な納品完了とさせていただきます。
本件、お役に立てましたら幸いです。
```

## 5. 評価のお願い（納品完了後）
```
このたびはご利用いただきありがとうございました。
もしよろしければ、今後の改善のため評価をいただけますと大変励みになります。
またお手伝いできることがあれば、いつでもお気軽にお声がけください。
```

## 6. リピート誘導（少し後）
```
先日はありがとうございました。
継続でのご依頼や、まとめてのご相談も承っております。
その際はお値段のご相談も可能ですので、お気軽にどうぞ。
```

## 7. 値引き交渉への対応
```
ご相談ありがとうございます。
品質を保つため大幅なお値引きは難しいのですが、
◯◯（分量調整・継続前提など）であれば◯◯円でご案内可能です。
ご検討いただけますと幸いです。
```

## 8. 対応できない依頼を断る
```
ご相談ありがとうございます。
申し訳ございませんが、今回の内容は当方では十分な品質をお約束できないため、
お引き受けを控えさせていただきます。
お力になれず恐縮ですが、より良いご縁がありますようお祈りしております。
```

## クレーム・トラブル時の鉄則
- まず謝意と傾聴。即反論しない。
- 内容を実務責任者(AI)に転送 → 冷静な対応文を作成。
- 解決が難しい場合はココナラ運営のサポートに相談（プラットフォームが仲介）。
