# 02. アカウント設計 ── 匿名運用とプロフィール

## 匿名運用の原則
- **本名・顔写真は一切不要。** ココナラはハンドルネーム＋アイコン画像で運用可能。
- ただし**出品には本人確認（運営側のみが確認、購入者には非公開）が必要**。これは法令・規約上の必須事項で、購入者にあなたの本名・顔が見えることはありません。
- アイコンは顔写真ではなく、ロゴ風の画像を実務責任者が用意します（Adobeツールで作成可能）。

## ハンドルネーム案（どれか選ぶ／変更可）
- `ことばの工房` （ライティング系で信頼感）
- `スイミー制作室`
- `カチコ｜資料・文章おたすけ`
- `Mojica（モジカ）`

> 決まったらお知らせください。アイコン（ロゴ）を作成します。

## プロフィール文（コピペ可・ライティング軸の例）

```
ご覧いただきありがとうございます。

文章・記事・資料作成を専門に、丁寧でスピーディーな納品を心がけています。
「伝わる」「成果につながる」を第一に、お客様の目的に合わせて
最適な形でご提案します。

◆ 対応分野
・ブログ／SEO記事の執筆
・各種ビジネス資料（提案書・企画書など）の作成
・プロフィール文／自己PR／応募書類の作成・添削
・LP・セールス文のライティング

◆ 大切にしていること
・納期厳守、こまめなご連絡
・修正対応も丁寧に
・初めての方も安心してご相談いただける対応

まずはお気軽にメッセージください。
ご相談・お見積りは無料です。
```

## 出品サムネイルの方針
- 文字を大きく載せた「サービス内容が一目で分かる」画像が反応率が高い。
- 実務責任者が各商品のサムネ案（テキスト＋配色）を作成します。

## セキュリティ・匿名性のチェックリスト
- [ ] プロフィール・やり取りで本名・住所・勤務先を書かない
- [ ] 納品ファイルの作成者情報（Word/PDFのプロパティ）に本名を残さない（→ 実務責任者が匿名で作成）
- [ ] 振込口座名義は購入者には公開されない（ココナラ運営のみ）
- [ ] SNS連携する場合も匿名アカウントで
