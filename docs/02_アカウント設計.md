# 02. アカウント設計 ── 匿名運用とプロフィール

## 匿名運用の原則
- **本名・顔写真は一切不要。** ココナラはハンドルネーム＋アイコン画像で運用可能。
- ただし**出品には本人確認（運営側のみが確認、購入者には非公開）が必要**。これは法令・規約上の必須事項で、購入者にあなたの本名・顔が見えることはありません。
- アイコンは顔写真ではなく、ロゴ風の画像を実務責任者が用意します（Adobeツールで作成可能）。

## 出品サムネイルの方針
- 文字を大きく載せた「サービス内容が一目で分かる」画像が反応率が高い。
- 実務責任者が各商品のサムネ案（テキスト＋配色）を作成します。

## セキュリティ・匿名性のチェックリスト
- [ ] プロフィール・やり取りで本名・住所・勤務先を書かない
- [ ] 納品ファイルの作成者情報（Word/PDFのプロパティ）に本名を残さない（→ 実務責任者が匿名で作成）
- [ ] 振込口座名義は購入者には公開されない（ココナラ運営のみ）
- [ ] SNS連携する場合も匿名アカウントで
