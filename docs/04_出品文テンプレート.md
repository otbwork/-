**サービス内容**
```

キーワード調査から構成、本文執筆まで一括で対応します。

◆ 内容
・3,000字程度のブログ／コラム記事 1本

・タイトル案を複数ご提案

◆ 進め方
1. テーマ・狙うキーワード・参考URLなどをお知らせください
2. 構成案をご提示
3. 本文を執筆し納品（Word／テキスト／Googleドキュメント対応）

◆ 修正
納品後2回まで無料で対応します。

◆ 納期
ご依頼から3日（お急ぎはご相談ください）

まずはお気軽にご相談ください。お見積り無料です。
```

**購入にあたってのお願い**
```
スムーズな納品のため、以下をお知らせください。
・記事テーマ
```
